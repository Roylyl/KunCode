# KunCode Agent Instructions

KunCode is an independent Code - OSS based project maintained by 603. Preserve
the KunCode product identity, cross-platform behavior, upstream license notices,
and third-party attribution when making changes.

Do not commit generated output such as `.build/`, `out/`, `node_modules/`, test
coverage, installers, or local caches. Keep Windows and macOS behavior aligned
unless a change is explicitly platform-specific.

For the inherited source architecture and coding guidelines, see the
[upstream-oriented Copilot instructions](.github/copilot-instructions.md).
